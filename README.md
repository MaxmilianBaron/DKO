# DSO — Digitální správa objektů

Offline aplikace pro technické kontroly a správu objektů.

[Otevřít interaktivní ukázku](https://maxmilianbaron.github.io/DSO/)

## Funkce

- evidence objektů a plánovaných kontrol
- průběžně ukládané formuláře, závady a poznámky
- fotografie, videa a odečty měřidel
- tvorba, náhled, tisk a sdílení PDF protokolů
- šifrované místní zálohy
- provoz bez povinného cloudového účtu
- V102: výběr protokolů v Historii a demo mazání jednotlivě nebo od data
- měřidla, více fotografií, označení snímku a e-mailově úsporný PDF workflow

## Veřejná ukázka

Repozitář obsahuje statickou ukázku uživatelského rozhraní s fiktivními daty. V102 preview navíc názorně ukazuje výběr a mazání demo protokolů v Historii; mazání se týká pouze lokálního stavu v prohlížeči a není napojené na produkční databázi. Fotografie v `assets/photos/` jsou pouze ilustrační/fake demo snímky. Repo neobsahuje produkční zdrojový kód, zákaznická data, databáze, přístupové údaje ani instalační balíčky.
